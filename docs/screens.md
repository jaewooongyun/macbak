# 화면과 맥박

## 화면

사이드바 맨 위의 **한눈에**는 모든 화면을 아우르는 첫 화면이라 묶음 밖에 둡니다. 나머지는 시스템·AI·자동화 세 묶음입니다. 항목마다 시스템 설정처럼 색 배지(묶음별 색 계열, 화면 안 주색과 같은 색)를 고정 폭 칸에 두고, 선택은 그 항목 색이 섞인 Liquid Glass 방울이 행 사이를 미끄러져 갑니다. 위·아래 화살표로도 옮겨집니다.

- **한눈에**: 맥박(BPM 박자로 뛰는 심장과 BPM·상태, CPU·GPU·메모리 압력 활동 링 셋), 그 아래 메모리·디스크·AI·정리할 수 있는 공간·정기 점검·앱 목록 타일. 타일을 누르면 해당 화면으로 갑니다.
- **디스크**: 실제 용량 막대와 이 Mac의 정리 후보 전체(Xcode 캐시, 앱 캐시·로그, 기기 지원 파일·시뮬레이터, AI 도구 캐시). "정리…" → 확인 시트 → 아래의 유리 캡슐이 패널로 늘어나며 실제로 지운 항목을 하나씩 체크합니다. 휴지통 카드의 "비우기…"로 휴지통도 비웁니다([정리 › 휴지통](cleanup.md#휴지통)).
- **메모리**: 구성 막대, 실시간 그래프, 압력, 스왑, 필요 없이 쓰이는 메모리(켜진 채 남은 시뮬레이터), 쓰지 않는 앱(직접 골라 종료), 메모리를 많이 쓰는 앱(보기만). 무엇이든 고르면 아래에 "정리…" 막대가 나타나고, 그 버튼 하나로 시뮬레이터 끄기와 고른 앱 종료를 함께 합니다.
- **AI 활동**: 제조사별로 쌓은 AI CPU 그래프, 제조사 카드(Anthropic·OpenAI·Google 등)마다 도구의 세션·최근 대화·백그라운드 작업, 실행 중인 프로세스와 도구별 CPU 추이.
- **AI 저장 공간**: AI 도구 폴더를 실제로 검사해 제조사 색으로 나눈 합계와 정리 후보(지워도 되는 것·골라서 지울 것·지우면 안 되는 것).
- **루프**: 정기 점검 켜기/끄기, 시각과 반복, 점검 기록, 로그인할 때 열기.
- **툴바**: 모든 화면에 맥박 알약(♥ 82 · 조금 바빠요)이 떠 있고, 누르면 한눈에로 갑니다.
- **메뉴 막대 / 설정 (⌘,)**: [메뉴 막대](menubar.md) 참고.

## 맥박

맥박은 CPU, GPU, 메모리 압력 중 **가장 바쁜 자원**을 박동수로 바꾼 값입니다. 모두 쉬면 60, 하나라도 꽉 차면 120입니다. 디스크 남은 공간은 부하가 아니라 용량이라 넣지 않습니다.

- CPU는 모든 코어의 사용 비율, GPU는 드라이버가 I/O Registry에 내는 `Device Utilization %`(추가 권한 불필요)입니다.
- 메모리는 사용률이 아니라 **메모리 압력**(100 − `kern.memorystatus_level`, 활성 상태 보기의 압력 그래프와 같은 개념)을 링과 숫자에 그대로 보여 줍니다. 맥박에는 압력 단계가 "보통"일 때 절반만 반영하고, "경고"는 최소 60%, "위험"은 최소 95%로 반영합니다. macOS는 메모리를 일부러 가득 채워 쓰므로, 그대로 반영하면 가만히 있어도 늘 "바빠요"가 됩니다.
- 일부러 차분하게 움직입니다. 약 10초 시간 상수로 평균을 내고, 상태마다 들어가는 문턱과 나오는 문턱을 다르게 둡니다(바쁨: 30%에 들어가 20% 아래에서 나옴). 그래서 순간 튀는 값 하나로 BPM이 뛰거나 상태가 바뀌지 않습니다(`Tests/MacbakTests/PulseTests.swift`).
- 활동 링은 값만큼 위에서 시계 방향으로 찹니다. 값이 클수록 링 위의 빛 띠가 빨리 흐르고, 링 끝점은 BPM 박자로 맥동합니다. 링을 가로지르는 짧은 눈금은 최근 1분 동안의 최고치입니다. 색은 CPU 분홍, GPU 남색이고 메모리는 압력 색(보통 초록·경고 주황·위험 빨강)입니다.
- 흐름과 맥동은 Core Animation이 30fps로 재생합니다. 창이 가려지거나 메뉴 막대 패널이 닫히면 멈추고, "동작 줄이기"를 켜면 늘 멈춰 있습니다.
