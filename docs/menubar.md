# 메뉴 막대

설정에서 켜고 끄는 항목 여섯 개를 자유롭게 조합합니다.

- 보이기/숨기기
- 보이는 항목: 맥박(부하 링과 BPM), 메모리 사용률, 디스크 남은 공간
- 표시 방식: 숫자, 움직이는 그래프(메모리는 최근 1분, 디스크는 사용량 막대)

맥박 항목은 가장 바쁜 자원의 평균 부하를 채운 링 하나가 아이콘이고, 숫자를 켜면 BPM이 붙습니다. 링이 늘 아이콘이라 그래프 설정은 맥박 항목에 영향을 주지 않습니다(2026-11-24, 전에는 작은 심전도).

맥박 항목은 2026-11-02에 추가했고 기본값은 꺼짐이라, 이미 쓰던 조합은 바뀌지 않습니다.

설정 창의 미리 보기는 밝은 줄과 어두운 줄을 나란히 보여 주다가, 아이템이 넓어 둘이 한 줄에 들어가지 않으면 위아래로 쌓습니다(2026-11-04 수정). 세 항목에 숫자와 그래프까지 켜면 아이템이 266pt가 됩니다. 전에는 이때 미리 보기가 설정 폼 전체를 460pt 창보다 넓혀 양옆이 잘렸습니다. `--snapshot`이 이 조합(`settings-all-*.png`)도 그립니다.

**패널**은 한눈에 화면의 축소판으로, 제어 센터처럼 둥근 모듈 다섯 덩어리입니다.

1. 맥박: 첫 줄에 "맥박"과 "BPM · 상태", 그 아래 세 겹 활동 링(바깥부터 CPU·GPU·메모리 압력, 가운데 BPM 박자로 뛰는 심장)과 세 칸 숫자입니다. 링은 선 6pt, 링 사이 5pt라 최고치 눈금끼리 닿지 않습니다. 세 칸은 링 옆 약 200pt를 고정 세 칸으로 나눕니다(적응형 격자는 이 폭에서 두 칸으로 접혔음). 메모리 칸 이름은 폭 때문에 "메모리"로 줄이고 VoiceOver는 "메모리 압력"으로 읽습니다.
2. 메모리와 디스크: 한 줄 두 칸에 숫자와 막대만 둡니다. 추이 그래프는 뺐습니다.
3. AI 사용량: 세션·도구 수, 메모리를 많이 쓰는 도구 세 개의 CPU와 메모리, 최근 1시간·24시간에 갱신된 대화 수(파일 수정 시각만 셉니다).
4. 정리(2026-11-04, 기호는 지우개 — 반짝이는 앱에서 기기 AI를 뜻해 2026-11-24에 바꿈): 맨 위가 **얕은 정리**, 그 아래가 **깊은 정리**입니다.
   - 얕은 정리의 "즉시 정리 · 크기" 버튼은 누르면 목록 확인 없이 바로 지우고, 진행과 결과를 패널 위 유리 팝업에 보여 줍니다. 들어가는 것은 "다시 생긴다"가 보증된 캐시 가운데 미리 체크된 것입니다. 3일 넘게 안 쓴 앱 캐시 가운데 규칙이 내용을 알아보는 것(`~/Library/Caches`, 앱 컨테이너의 Caches, Chromium·Electron 앱의 캐시 폴더), 1일 넘게 안 쓴 Xcode 빌드 캐시(테스트 결과 없음, 작업 공간 기록이 없는 것 포함), Xcode 공용 컴파일 캐시, 30일 넘은 로그, 14일 넘게 안 쓴 기기 지원 파일, AI 도구 카탈로그의 캐시와 오래된 파일, 개발 도구 표에서 내려받지 않고 다시 만드는 캐시(Gradle build-cache·스크립트 캐시, go-build)가 여기에 듭니다. go-build는 옛 내려받기 목록에서 뺐습니다(2026-11-04, 컴파일 결과라 내려받지 않음).
   - 다시 받아야 하는 캐시(패키지 관리자, macOS 배경화면 동영상), 정체를 모르는 `~/.cache`의 도구 캐시, 규칙이 모르는 앱 캐시, 안쪽 어디엔가 문서·메일·인증서 묶음(`.pdf`·`.docx`·`.eml`·`.p12` 등)이 있는 캐시, 기기 AI 제안, 14일 안의 기기 지원 파일, 시뮬레이터(조용한 것은 대시보드에서 미리 체크)는 얕은 정리에서 빠지고 대시보드에만 남습니다. 지갑 파일(`wallet.dat`)은 어디에 있든 그 줄을 "지우면 안 되는 것"으로 돌립니다. 얕은 실행은 지우기 직전에 그 줄이 여전히 얕은 정리 대상이고 대상 경로가 같은지 다시 확인하고, 대상을 다시 훑어 새로 생긴 키·지갑·문서가 없는지 봅니다. AI 도구 카탈로그의 캐시에도 같은 깊은 검사를 합니다. 지우기 직전의 모든 검사(사용 중, 식별자, 경로 가드, 최신 판정)는 대시보드와 같습니다. 디스크와 AI 저장 공간 결과가 둘 다 10분 안의 것일 때만 버튼이 보이고, 아니면 "다시 검사"가 두 검사를 다시 돕니다. 패널이 디스크 검사를 스스로 시작하지는 않습니다.
   - 깊은 정리 줄은 대시보드에서만 고를 수 있는 것의 수와 크기, 기기 AI의 진행과 제안 수를 보여 주고, "대시보드"를 누르면 메인 창이 디스크 화면으로 열립니다(창이 닫혀 있어도, 열려 있어도).
   - 메모리(쓰지 않는 시뮬레이터 끄기)와 휴지통(Finder에 비우기 요청)은 지금처럼 확인을 거칩니다. 패널을 닫으면 열려 있던 확인 팝업은 취소됩니다.
5. 다음 정기 정리 시각(도는 중이면 "정기 정리 중…", 그중 지우는 동안에는 작은 "중단"), 창 열기·설정·종료. 패널의 강조 버튼은 "즉시 정리" 하나이고 창 열기는 보조 버튼입니다.

패널 창은 앱이 시작할 때 숨긴 채 만들어지고 닫아도 숨기기만 하므로 `onAppear`는 한 번만 옵니다. 그래서 창이 실제로 화면에 나온 순간(`animatesOnlyWhenShown`의 `onChange`)에 AI 샘플링을 바로 한 번 돌리고, AI 저장 공간 검사가 10분보다 오래됐으면 다시 검사합니다. 검사는 AI 프로세스를 한 번 읽은 **뒤에** 합니다. 먼저 하면 어떤 캐시가 쓰이지 않는지 몰라 전부 "지우면 안 되는 것"이 됩니다. 검사는 약 20초 걸리고 그동안 AI 캐시 줄에 "검사하는 중…"이 보입니다. 정기 점검 줄에서는 샘플 기반의 "정리 가능 N개"를 뺐습니다. 실제 검사 숫자와 한 패널에 나란히 놓이면 헷갈리기 때문입니다.

항목을 모두 끄면 Macbak 아이콘(심전도 기호)만, 표시 방식을 모두 끄면 항목 아이콘만 보입니다. 메뉴 막대는 글자와 그림만 그릴 수 있어서, 그래프까지 포함한 전체를 템플릿 이미지 한 장으로 그립니다. 라이트·다크·선택 상태의 색은 시스템이 입히므로, 메모리 압력은 색이 아니라 아이콘 모양(경고 기호)으로 알립니다.

| 조합 | 실제 아이템 폭 |
|---|---|
| 메모리 숫자 (기본) | 66.5pt |
| 메모리 아이콘만 | 35pt |
| 메모리 그래프 | 66pt |
| 메모리 숫자+그래프 | 97.5pt |
| 디스크 그래프 | 61pt |
| 둘 다 숫자 | 138pt |
| 둘 다 그래프 | 117pt |
| 둘 다 숫자+그래프 | 194pt |
| 항목 없음 | 33pt |

폭은 실행 중인 앱의 메뉴 막대 아이템을 접근성 API로 잰 값입니다(2026-11-02). 그림 폭에 시스템 여백 약 17.5pt가 더해집니다. "항목 없음"은 아이콘을 심전도 기호로 바꾸기 전에 잰 값입니다.

- 메뉴 막대가 꽉 찬 노치 MacBook에서는 아이템이 노치 뒤로 밀려 가려질 수 있습니다. 이럴 때는 "메모리 아이콘만"(35pt)을 권합니다. 압력이 높아지면 아이콘 자체가 경고 기호로 바뀝니다.
- 메모리 그래프는 테두리 안의 수위로 최근 1분 사용률을 0–100% 고정 눈금으로 그리고, 2초마다 한 칸씩 움직입니다. 메모리는 천천히 바뀌어서 움직임이 작습니다.
- 디스크 숫자는 남은 공간("479GB"), 디스크 그래프는 사용량 막대입니다.
- 숫자 자리는 두 자리 폭을 미리 잡아서, 두 자리 값 사이에서는 아이템이 흔들리지 않습니다(100%가 되면 한 번 넓어짐).
- 메뉴 막대에서 숨겨도 앱은 계속 실행됩니다. 창을 모두 닫은 뒤 Dock 아이콘을 누르면 메인 창이 다시 열립니다.
